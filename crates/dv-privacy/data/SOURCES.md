# Sources of the filter's data files

The app never downloads anything for the filter. These files are built once, by a developer,
and compiled into the binary.

| File | What it is | Source | License |
|---|---|---|---|
| `first_names.txt`, `word_names.txt`, `surnames.txt`, `localities.txt`, `nicknames.txt`, `common_words.txt`, `latin_allowlist.txt` | Hand-written lists | This project | Project license |
| `words-1.tsv` … `words-6.tsv` | ~300,000 Hebrew word forms, sorted and split under the 1 MB file limit, with a frequency bucket (`1 + floor(log2(count))`) | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) 2018 `he_full.txt` (OpenSubtitles), forms seen at least 5 times, plus every form in the two UD treebanks below | CC BY-SA 4.0 (Hermit Dave; OpenSubtitles.org) |
| (merged into `words-*.tsv`) | Written forms from Wikipedia and Knesset protocols, which subtitles lack | [UD_Hebrew-IAHLTwiki](https://github.com/UniversalDependencies/UD_Hebrew-IAHLTwiki) and [UD_Hebrew-IAHLTknesset](https://github.com/UniversalDependencies/UD_Hebrew-IAHLTknesset), train + dev + test | CC BY-SA 4.0 (IAHLT; Zeldes et al.) |

`words-*.tsv` are derived data and are themselves under CC BY-SA 4.0. They are generated by
`scripts/build_lexicons.py`; to rebuild, download the source files listed in its docstring into
a folder and run `python3 scripts/build_lexicons.py <folder>`. The output is byte-for-byte
reproducible. Do not edit them by hand.

No source under a non-commercial or AGPL license (for example Hspell, the eyaler name lists or
UD_Hebrew-HTB) may be added. Name lists stay hand-written until an open, attributable source
is available offline (the CBS name statistics on data.gov.il are blocked from the build
environment).
