# מה פסיכולוגית התפתחותית צריכה מהתוכנה

סקירה מנקודת המבט של עינת, לפי שלבי העבודה על אבחון. לכל צורך: מה יש, ומה מתוכנן. ✅ קיים · 🟡 חלקי · ⬜ מתוכנן.

## 1. פתיחת תיק ואיסוף חומרים
| צורך | מצב |
|---|---|
| תיק לכל ילד, עם שמות שיוסתרו (ילד, הורים, אחים, גננת, מטפלים) | ✅ |
| גיל בעת האבחון בשנים וחודשים, או חישוב מתאריך לידה (שלא נשמר) | ✅ |
| הסכמת הורים רשומה, שבלעדיה אין שליחה | ✅ |
| ייבוא Word ו-PDF, כולל טבלאות, רשימות, הסתרת כותרות ושם יוצר | ✅ |
| קובצי טקסט בקידוד עברית ישן (Windows-1255) | ✅ |
| מסמכים סרוקים (צילום של דף) | ⬜ נחסמים היום עם הסבר. OCR מקומי שוקלים בהמשך, רק אם יש צורך. |
| קובצי Word ישנים (.doc) ו-ODT | 🟡 ODT ✅ (LibreOffice, Google Docs), באותם כללים כמו Word. ‎.doc נחסם עם הסבר ("לשמור כ-docx"). |
| רישום מפגש ותצפית בכתיבה חופשית | ✅ |

## 2. ציונים ושאלונים
| צורך | מצב |
|---|---|
| הזנת ציונים ל-WPPSI-IV, WISC-V, Bayley-4, ABAS-3, ASRS, CBCL, ADOS-2, CARS-2 | ✅ |
| טווח ואחוזון מחושבים בתוכנה, לא ב-Claude | ✅ |
| פער בין מדדים מסומן | ✅ |
| אישור הטבלאות על ידי עינת | ⬜ `knowledge/instruments.md` |
| Vineland-3, Conners, BRIEF-P, מבחני שפה | ⬜ לפי מה שעינת מעבירה |
| טבלת ציונים בדוח ה-Word (ולא רק בטקסט) | ✅ נספח טבלאות לכל כלי |

## 3. כתיבת הדוח
| צורך | מצב |
|---|---|
| טיוטה לכל סעיף מהמקורות, עם מקור לכל פסקה | ✅ |
| אישור, עריכה או מחיקה של כל פסקה; פסקאות שלה | ✅ |
| סתירות בין מקורות מסומנות, ולא מוכרעות על ידי Claude | ✅ |
| "[חסר: …]" במקום המצאה | ✅ |
| סיכום והמלצות שנבנים מהסעיפים שאושרו | ✅ |
| לשון זכר/נקבה לפי הילד | ✅ |
| פרופיל סגנון שנבנה מהדוחות שלה | ⬜ ממתין להחלטה P-04 |
| המלצות לפי תבניות שלה (ריפוי בעיסוק, קלינאות, הדרכת הורים, התאמות בגן) | ⬜ |

## 4. חיסיון ואבטחה
| צורך | מצב |
|---|---|
| שמות, תאריכים ומספרים מזהים לא יוצאים מהמחשב | ✅ |
| מסך "מה יוצא מהמחשב" לפני כל שליחה | ✅ |
| שם שלא ברשימה עוצר את השליחה עד החלטה | ✅ |
| נעילה אוטומטית, נעילה ב-Ctrl+L, ניקוי המסך בנעילה | ✅ |
| דוח Word מוצפן בסיסמה, בלי שם הילד בשם הקובץ | ✅ |
| יומן פעולות שעינת יכולה לראות | ✅ בהגדרות, בעברית (D-025) |
| גיבוי מוצפן לדיסק חיצוני | ✅ עם תזכורת שבועית ותרגול שחזור (D-024) |
| תזכורת לתקופת שמירה (P-07) | ✅ תזכורת בלבד, בלי מחיקה אוטומטית (D-025) |
