# מה פסיכולוגית התפתחותית צריכה מהתוכנה

סקירה מנקודת המבט של עינת, לפי שלבי העבודה על אבחון. לכל צורך: מה יש, ומה מתוכנן. ✅ קיים · 🟡 חלקי · ⬜ מתוכנן.

**נבדק מול הקוד ב-26.10.2026.** הגרסה הקודמת סימנה כ"מתוכנן" דברים שכבר נבנו (פרופיל הסגנון, מכתב להורים ולגן, אבחון מעקב, OCR, ‎.doc, אישור הטבלאות), וכ"קיים" שני דברים שהשתנו מאז (החלון לפני כל שליחה, ועצירה על שם לא מוכר). כאן כל שורה אומרת מה נכון היום, ואיפה זה בקוד או בהחלטה.

## 1. פתיחת תיק ואיסוף חומרים
| צורך | מצב |
|---|---|
| תיק לכל ילד, עם שמות שיוסתרו (ילד, הורים, אחים, גננת, מטפלים) | ✅ |
| גיל בעת האבחון בשנים וחודשים, או חישוב מתאריך לידה (שלא נשמר); מוצג תמיד במילים | ✅ (D-084) |
| הסכמת הורים רשומה, שבלעדיה אין שליחה | ✅ (D-008). 🟡 עדיין לא נרשם **לאיזה ספק** ההורים הסכימו (AI-1, `external/CONSENT_DRAFT.md`) |
| ייבוא Word ו-PDF, כולל טבלאות, רשימות, הסתרת כותרות ושם יוצר | ✅ |
| קובצי טקסט בקידוד עברית ישן (Windows-1255) | ✅ |
| מסמכים סרוקים (צילום של דף, PDF בלי טקסט) | ✅ OCR מקומי (Tesseract), בלי ענן (D-048, `dv-ingest/src/ocr.rs`). 🟡 ב-Windows בלבד; ב-Mac מסמך סרוק עדיין נדחה עם הסבר (D-101) |
| קובצי Word ישנים (.doc), ODT ו-RTF | ✅ באותם כללים כמו Word (D-048, `dv-ingest/src/doc.rs`, `odt.rs`, `rtf.rs`) |
| רישום מפגש ותצפית בכתיבה חופשית | ✅ |
| מבנה המכון לכל תיק חדש | ✅ (D-066, `templates/institute-v1.json`) |
| "מה עוד חסר" בחומרים (אינטייק, מסגרת, תצפית, ציונים, אבחונים קודמים) | ✅ (D-088) |
| סיכום קצר של כל חומר, ורשומה לכל דוח קודם | ✅ (D-069) |

## 2. ציונים ושאלונים
| צורך | מצב |
|---|---|
| הזנת ציונים ל-WPPSI-IV, WPPSI-III, WISC-V, Bayley-4, MSEL, ABAS-3, Vineland-3, ASRS, CBCL 1½–5, BRIEF-P, ADOS-2, CARS-2 | ✅ (`dv-domain/src/scores.rs`), עם פרופיל שמתעדכן בזמן ההקלדה (D-094) |
| טווח ואחוזון מחושבים בתוכנה, לא ב-AI | ✅ |
| פער בין מדדים מסומן | ✅ |
| אישור הטבלאות על ידי עינת | ✅ בהגדרות ← המבחנים, לכל מבחן "מאושר" או "לא מעבירה את זה" (D-098). מה שהיא עונה הוא שלה; עד שתענה, המבחן מחכה |
| Conners ומבחני שפה ייעודיים | ⬜ לפי מה שעינת מעבירה. (שפה קולטת ומבטאת נמדדות היום בתוך Bayley-4 ו-MSEL) |
| טבלת ציונים וגרף בדוח | ✅ נספח טבלאות וגרף עמודות לכל כלי (D-049) |
| רמת חומרה לפי DSM-5 שהיא קובעת | ✅ (D-080) |

## 3. כתיבת הדוח
| צורך | מצב |
|---|---|
| טיוטה לכל סעיף מהמקורות, עם מקור לכל פסקה | ✅ |
| אישור, עריכה או מחיקה של כל פסקה; פסקאות שלה; גרסאות קודמות של פסקה | ✅ (D-036, D-046) |
| סעיפים שהיא כותבת בעצמה, ו"לנסח מהנקודות שלי" | ✅ (D-068) |
| סתירות בין מקורות מסומנות, ולא מוכרעות על ידי ה-AI | ✅ |
| "[חסר: …]" במקום המצאה | ✅ |
| סיכום והמלצות שנבנים מהסעיפים שאושרו | ✅ |
| בדיקת הדוח כולו אחרי שכל הסעיפים אושרו (סתירה בין סעיפים, חזרות, ממצא בלי בסיס) | ✅ (D-097) |
| לשון זכר/נקבה לפי הילד | ✅ |
| פרופיל סגנון שנבנה מהדוחות שלה | ✅ "הסגנון שלי": שליחה חד-פעמית של דוחות ישנים מסוננים, אישור של כל פריט, ולמידה מקומית מהתיקונים שלה (D-042, D-043, D-052, D-055, D-089, D-100). מחכה לתשובת העו"ד לפני שימוש בדוחות אמיתיים (שאלה 34) |
| איך היא מפרשת כל תת-מבחן, ומה היא מסיקה מממצא | ✅ (D-071, D-075, D-100), רק אחרי שאישרה |
| המלצות לפי מה שהיא נותנת בדרך כלל (ריפוי בעיסוק, קלינאות, הדרכת הורים, התאמות בגן) | ✅ ההמלצות והאבחנות שחוזרות בדוחות שלה מוצעות לבחירה, עם "ב-X מ-Y דוחות דומים" (D-074) |
| "כתיבת כל הדוח" בלחיצה אחת, ברקע | ✅ (D-079) |
| התייעצות עם ה-AI על תיק או בכלל, ושיחות שנשמרות | ✅ (D-017, D-027) |

| דוח Word ו-PDF בלי שם הילד בשם הקובץ (בלי סיסמה, לבקשתה, D-081) | ✅ |
