# מפרט מוצר

## למי ולמה
**עינת** היא פסיכולוגית התפתחותית שמאבחנת ילדים (בעיקר בגיל הגן): אבחון קוגניטיבי, אבחון תקשורת ואוטיזם, ואבחון רגשי. כתיבת הדוח לוקחת לה שעות. היא רוצה כלי ש:
1. בונה את הדוח במבנה הקבוע שלה (`REPORT_STRUCTURE.md`);
2. כותב **בסגנון הניסוח שלה**;
3. משתמש רק במידע על הילד הנוכחי, **בלי להעביר תוכן מדוחות קודמים**;
4. מפרש ציונים של כלי אבחון על סמך ידע מקצועי מאושר;
5. מאפשר לה **לדבר עם Claude ברצף**: להרחיב, לשנות, לנתח ולבקש הצעות;
6. **שומר על חיסיון מוחלט:** המידע רגיש ביותר (קטינים, מידע נפשי-רפואי).

## עקרונות
- **שום פרט מזהה לא יוצא מהמחשב.** צנרת סינון מקומית, fail-closed. השמות חוזרים לטקסט רק מקומית.
- **מה כן נשלח ל-Claude:** תוכן קליני ללא זהות (ממצאים, ציונים, תיאורי התנהגות). זו החלטה מודעת, ומתועדת ב-`SECURITY.md`.
- **הכל מוצפן במנוחה.**
- **עינת בשליטה:** רואה מה נשלח, מאשרת כל פסקה, בוחרת את האבחנה.
- **אין סיכון אפס.** המטרה: סיכון מזערי, מתועד, שאפשר להגן עליו מקצועית.

## זרימת עבודה
1. פותחת את התוכנה עם סיסמה או ביומטריה.
2. פותחת תיק וממלאת טופס זהויות (כל מי שעשוי להיות מוזכר).
3. **חלק א' – רקע:** מקלידה אינטייק הורים, מעלה דוחות קודמים (PDF / Word), מתעדת שיחות עם אנשי מקצוע ועם הגננת. מדברת עם Claude, והוא מנסח את סעיפי הרקע.
4. **חלק ב' – אבחון:** התרשמות, ציוני מבחנים (WPPSI / Bayley, ADOS-2, CARS, ASRS, ABAS, אכנבך), אבחון רגשי (HTP, CAT, משחק חופשי, תצפית משפחתית). Claude מנסח, ומציע התאמה לקריטריוני DSM-5. האבחנה עצמה היא החלטה שלה.
5. **חלק ג':** Claude מסכם מתוך סעיפים שכבר אושרו, ומציע המלצות.
6. מפיקה Word בתבנית שלה, עם השמות האמיתיים, מוגן בסיסמה.

## הקשר משפטי (להתייעצות, לא ייעוץ)
חוק הגנת הפרטיות (כולל תיקון 13) ותקנות אבטחת מידע; חוק הפסיכולוגים וכללי האתיקה; חובת סודיות מקצועית. התוכנה מספקת תיעוד (`SECURITY.md`, `INCIDENT_RESPONSE.md`, `CONSENT_DRAFT.md`). עינת תבדוק אותו עם יועץ פרטיות.

## חשבונות
- **הפיתוח:** בחשבון של אור, עם מפתח API לבדיקות, על נתונים בדויים בלבד.
- **ההפעלה:** עינת מזינה בהתקנה **מפתח API משלה** (Anthropic Console, נפרד מהמנוי ל-Claude), והוא נשמר ב-keychain. `SETUP_HE.md` מסביר איך לפתוח חשבון API, ואילו הגדרות לבדוק: שמירת מידע ו-Zero Data Retention.
