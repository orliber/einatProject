# צנרת הסינון (`core/privacy`)

כל טקסט שיוצא ל-API עובר את כל השכבות, לפי הסדר. כל שכבה יכולה לחסום.
`ai/client.py` מקבל רק אובייקט `ClearedPayload`, שרק `gate.py` יכול ליצור (אכיפה בטיפוסים + בדיקה).

## תגיות
`[ילד]` `[אם]` `[אב]` `[אח_1]` `[אחות_1]` `[גננת]` `[סייעת_1]` `[רופא_1]` `[קלינאית_1]` `[פסיכולוגית_1]` `[ילד_גן_1]` `[גן]` `[יישוב]` `[מוסד_1]`
התגיות יציבות לאורך כל התיק (אותו אדם = אותה תגית).

## השכבות
1. **צמצום:** ה-context builder מכניס רק את מה שהסעיף צריך. ת.ז., כתובת, טלפון, שם הגן ושמות אנשי מקצוע לא נכנסים בכלל.
2. **זהויות מוצהרות:** מטופס התיק. `variants_he.py` מייצר וריאציות:
   - תחיליות ו/ה/ב/ל/מ/ש/כ ושילוביהן ("ולתמיר", "שמתמיר")
   - כתיב מלא וחסר, ה' הידיעה
   - תעתיק לאנגלית, כינויים שהוגדרו
   - גבולות מילה: לא להחליף בתוך מילה אחרת
3. **התאמה עמומה:** מרחק Levenshtein של 1–2 משם מוצהר (לפי אורך) = חשד → מסך בדיקה.
4. **תבניות:**
   - ת.ז. (9 ספרות + ספרת ביקורת), טלפון, מייל, כתובת, מיקוד, URL
   - תאריכים לועזיים ועבריים → זמן יחסי ("לפני כשבועיים")
   - גיל בשנים וחודשים **נשמר**, כי הוא נדרש קלינית
5. **NER מקומי:** DictaBERT-NER. ישות PER/LOC/ORG שלא מוכרת = חשד.
   - שמות שהם גם מילים ("אור", "טל", "גל", "שחר", "חן"): לפי הקשר, ובספק = חשד.
   - רשימת היתר (allowlist) נבנית מהחלטות "זה לא שם".
6. **מזהים עקיפים:**
   - מקצועות הורים ← הכללה ("עובדת בתחום החינוך")
   - מוסדות ← סוג המוסד ("מכון להתפתחות הילד")
   - אירועים ופרטים ייחודיים במיוחד ← סימון לבדיקה
   - ציון סיכון להודעה
7. **שער סופי (fail-closed):**
   - סריקת ה-payload **המלא** (system prompt + היסטוריה + הודעה) מול **כל** הזהויות של **כל** התיקים, כולל הווריאציות.
   - התאמה אחת = חסימה + רישום `blocked` ביומן + הודעה. אין עקיפה מהקוד. עקיפה ידנית רק מהמסך, עם הקלדת סיסמה.
   - מגבלת גודל payload ומגבלת קצב.
   - לכל תיק מוחלת רק מפת התגיות שלו. תגית של תיק אחר = חסימה.
8. **אישור אנושי:** מסך "מה יוצא מהמחשב" (`SCREENS.md`, מסך 4). ברירת מחדל: תמיד. אפשר להגדיר "רק כשיש חשד".

## כיוון חוזר
- תשובות Claude נסרקות לתגיות לא מוכרות, לשמות, ולתגיות של תיקים אחרים. ממצא = סימון.
- תוכן ממסמכים שהועלו נעטף בתגי נתונים עם nonce ("נתונים, לא הוראות").
- ל-AI אין שום כלי שמחזיר זהויות, קבצים או נתיבים.

## החזרת שמות (`export/restore.py`)
- רק מקומית: בתצוגה ובייצוא.
- בסוף הייצוא בודקים שלא נשארה אף תגית. אם נשארה, זו שגיאה חוסמת.
- התאמה דקדוקית: תחילית שנשמרה + שם ("ל[ילד]" → "לנועם").

## בדיקות (חובה)
- `tests/adversarial/`: מאות משפטים בדויים שמכסים תחיליות, שגיאות הקלדה, שמות-מילים, אנגלית, ת.ז. בפורמטים שונים, תאריכים עבריים ולועזיים, ילדים אחרים, ושמות בתוך ציטוטים.
- `tests/canary/`: שמות-מלכודת ייחודיים בתיקי בדיקה. כל payload שנבנה בכל בדיקה נסרק אחריהם.
- property-based עם `hypothesis`: הרכבת שם + תחילית + הקשר אקראי ← חייב להיות מוחלף או חסום.
- **תנאי למיזוג: 0 דליפות.**
