# התקנה – כספת האבחון

> **עד שארבעת התנאים מתקיימים (אישור ZDR בכתב, בדיקה משפטית, טופס הסכמת הורים, מבדק חדירה): רק תיקים בדויים.** בלי מפתח API התוכנה עובדת במצב הדגמה, ושום דבר לא יוצא מהמחשב.

## עינת: התקנה (פעם אחת, דקה)
1. **לוחצים פעמיים** על הקובץ `DiagnosticVault-Setup.exe`.
2. מופיע חלון קטן עם פס התקדמות, בעברית. **אין שאלות ואין כפתורים ללחוץ.**
3. בסוף **התוכנה נפתחת לבד**, ויש לה סמל על שולחן העבודה ובתפריט התחל: **"כספת האבחון"**.

זהו. לא צריך הרשאות מנהל, ולא צריך להתקין שום דבר אחר.

**אם מופיע מסך כחול "Windows protected your PC":** לוחצים **More info** ואז **Run anyway**. זה קורה פעם אחת, כי הקובץ עוד לא חתום דיגיטלית (חתימה מתוכננת: P-06). אחרי החתימה המסך הזה ייעלם.

### בפתיחה הראשונה
התוכנה מובילה צעד אחרי צעד:
- **סיסמה:** משפט קצר שקל לזכור, 12 תווים לפחות.
- **ערכת שחזור:** מדפיסים ושומרים במגירה נעולה, לא במחשב ולא בטלפון. זו הדרך היחידה לפתוח את הכספת אם הסיסמה נשכחת.
- **השם שלך ושם הקליניקה:** יוסתרו תמיד לפני שליחה.

**מחשב חדש, ויש גיבוי?** בפתיחה הראשונה לוחצים **"מחשב חדש? יש לי גיבוי"**, בוחרים את קובץ הגיבוי ופותחים בסיסמה. הכל חוזר.

### עדכון לגרסה חדשה
לוחצים פעמיים על הקובץ החדש, בדיוק כמו בהתקנה. התיקים, ההגדרות והסיסמה נשארים.

### הסרה
הגדרות Windows ← אפליקציות ← "כספת האבחון" ← הסרה. **לא לסמן "מחק את נתוני האפליקציה"**, אלא אם רוצים למחוק את הכספת עצמה (אחרי גיבוי).

## אור: איך מגיעים לקובץ
**הדרך הקבועה (מומלצת):** מוציאים גרסה, והקובץ מקבל קישור קבוע.
1. ב-GitHub: **Releases ← Draft a new release** עם תגית חדשה (למשל `v0.2.0`) ← Publish, או מהמחשב: `git tag v0.2.0 && git push origin v0.2.0`.
2. אחרי כ-15 דקות, בדף ה-Release יש `DiagnosticVault-Setup.exe` (וקובץ `.sha256` לבדיקת שלמות).
3. הקישור לגרסה האחרונה תמיד זהה:
   `https://github.com/orliber/einatProject/releases/latest/download/DiagnosticVault-Setup.exe`
   אם הריפו פרטי, הקישור עובד רק למי שמחובר ל-GitHub עם הרשאה. אז מורידים ושולחים לעינת את הקובץ עצמו (מייל, WhatsApp, דיסק און קי).

**לפני ה-Release, לבדיקה:** Actions ← CI ← Run workflow על הענף, ובסוף הריצה ב-Artifacts: `diagnostic-vault-windows`.

**בלי GitHub Actions (למשל כשנגמרו הדקות):** אפשר לבנות את המתקין גם ממחשב Linux: `sudo apt install mingw-w64 nsis cmake nasm`, `rustup target add x86_64-pc-windows-gnu`, ואז בתיקייה `apps/desktop`: `pnpm tauri build --target x86_64-pc-windows-gnu --bundles nsis`. הקובץ יוצא ב-`target/x86_64-pc-windows-gnu/release/bundle/nsis/`. גרסת ה-Release (מ-Windows) נשארת הרשמית.

**בדיקת שלמות (לא חובה):** ב-PowerShell, `Get-FileHash DiagnosticVault-Setup.exe` צריך להחזיר את הערך שבקובץ `.sha256`.

**להתקנה עם כל המסכים הרגילים** (למשל לבחור תיקייה): `DiagnosticVault-Setup.exe /GUI`.

## Mac (לבדיקה אצל אור בלבד)
פותחים את ה-`.dmg` מה-Artifacts וגוררים ל-Applications. בפתיחה הראשונה: הגדרות מערכת ← פרטיות ואבטחה ← **"פתח בכל זאת"**. פעם אחת.

## שאלות נפוצות
- **שכחתי סיסמה:** במסך הכניסה "שכחתי את הסיסמה", מקלידים את ערכת השחזור, ואז הגדרות ← החלפת סיסמה.
- **איפה הקבצים?** בתיקייה של התוכנה במחשב, מוצפנים. אסור להעביר אותה ל-OneDrive, Dropbox או Google Drive: התוכנה תסרב לעבוד משם.
- **איפה הדוח?** בתיקיית ההורדות, כקובץ Word מוגן בסיסמה.
- **רק לנסות בלי להתקין?** יש הדמיה בדפדפן עם תיקים בדויים (הקישור אצל אור). אין בה כספת, ואין להכניס אליה מידע אמיתי.
