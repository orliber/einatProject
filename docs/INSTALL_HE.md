# התקנה ומסירה – כספת האבחון

שני חלקים: מה אור עושה כדי להעביר את התוכנה, ומה עינת עושה במחשב שלה.

> **עד שארבעת התנאים מתקיימים (אישור ZDR בכתב, בדיקה משפטית, טופס הסכמת הורים, מבדק חדירה) – רק תיקים בדויים.** בלי מפתח API התוכנה עובדת במצב הדגמה ושום דבר לא יוצא מהמחשב.

## א. אור: להוריד ולשלוח
1. ב-GitHub: **Actions** ← הריצה האחרונה הירוקה של CI על `main` ← בתחתית הדף, **Artifacts**.
   קובצי ההתקנה נבנים רק אחרי מיזוג ל-main, כדי לחסוך דקות. לגרסה מענף אחר: **Actions ← CI ← Run workflow**, ובוחרים את הענף.
2. מורידים:
   - **Windows (עינת):** `diagnostic-vault-windows`. בתוך ה-ZIP יש קובץ אחד: `Diagnostic Vault_…_x64-setup.exe`.
   - **Mac (לבדיקה אצל אור):** `diagnostic-vault-macos`, ובו קובץ `.dmg`.
3. שולחים לעינת רק את קובץ ה-`setup.exe` (במייל, ב-WhatsApp, ב-Drive או בדיסק און קי).
4. הקבצים נשמרים ב-GitHub 14 יום. אחרי זה מורידים מריצה חדשה יותר.

## ב. עינת: התקנה ב-Windows (פעם אחת, כ-2 דקות)
1. לוחצים פעמיים על הקובץ `…setup.exe`.
2. אם מופיע מסך כחול **"Windows protected your PC"**: לוחצים **More info** ואז **Run anyway**. זה קורה כי הקובץ עוד לא חתום דיגיטלית. החתימה מתוכננת בהמשך (Azure Trusted Signing), ואחריה המסך הזה ייעלם.
3. **Next ← Install ← Finish.** לא צריך הרשאות מנהל. התוכנה מותקנת רק למשתמשת שלך.
4. התוכנה נפתחת. בפעם הראשונה:
   - **סיסמה:** משפט קצר שקל לזכור, 12 תווים לפחות.
   - **ערכת שחזור:** מדפיסים או מעתיקים לדף, ושומרים במגירה נעולה, לא במחשב ולא בטלפון. זו הדרך היחידה לפתוח את הכספת אם הסיסמה נשכחת.
   - **השם שלך ושם הקליניקה:** יוסתרו תמיד לפני שליחה.

## ג. אור: Mac (לבדיקה)
1. פותחים את ה-`.dmg` וגוררים את האפליקציה ל-Applications.
2. בפתיחה הראשונה מופיעה אזהרה. פותחים **הגדרות מערכת ← פרטיות ואבטחה**, ולוחצים **"פתח בכל זאת"** (Open Anyway). פעם אחת בלבד.

## ד. שאלות נפוצות
- **שכחתי סיסמה:** במסך הכניסה לוחצים "שכחתי את הסיסמה", מקלידים את ערכת השחזור ובוחרים סיסמה חדשה.
- **איפה הקבצים?** בתיקייה של התוכנה במחשב, מוצפנים. אסור להעביר את התיקייה ל-OneDrive, Dropbox או Google Drive. התוכנה תסרב לעבוד משם.
- **איפה הדוח?** בתיקיית ההורדות, כקובץ Word מוגן בסיסמה. הסיסמה מוצגת בזמן ההפקה.
- **עדכון גרסה:** מתקינים את הקובץ החדש מעל הישן. התיקים נשארים.
- **רק לנסות בלי להתקין?** יש הדמיה בדפדפן עם תיקים בדויים (הקישור אצל אור). אין בה כספת, ואין להכניס אליה מידע אמיתי.
