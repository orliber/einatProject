# מודל איומים – כספת האבחון

> מתודולוגיה: **STRIDE** לאבטחה, **LINDDUN** לפרטיות, ו-**OWASP LLM Top 10 (2025)** לשכבת ה-AI.
> גרסה 1: שלב 0, 2026-09-28. מתעדכן בכל שלב, ולפחות פעם ב-18 חודשים (תקנות אבטחת מידע, רמה גבוהה).
> מבוסס על הארכיטקטורה ב-`ARCHITECTURE.md` (Tauri 2 + Rust, בלי Python בזמן ריצה).

## 1. היקף והנחות
- משתמשת אחת (עינת), על מחשב אחד (Windows או macOS). אין שרת, ענן, סנכרון או ריבוי משתמשים.
- תעבורה יוצאת מותרת רק ל-`api.anthropic.com`, עם ZDR.
- **הנחה:** מערכת ההפעלה לא נפרצה ברמת root/admin. אם היא נפרצה, התוקף רואה את מה שעינת רואה על המסך בזמן שהכספת פתוחה. אנחנו **מצמצמים** את הנזק (כספת נעולה = מוצפנת, ומפתח קשור לחומרה), אבל לא מבטיחים הגנה מלאה במצב כזה.
- **הנחה:** עינת לא פועלת בזדון. היא עלולה לטעות, ולכן ברירות המחדל מגינות גם מפני טעויות.
