# דגמי מסכים

קבצי `.dc.html` הם דגמים מכלי העיצוב של Claude: HTML עם JS קטן, שנשען על runtime שלא כלול כאן, ולכן הם לא נפתחים ישירות בדפדפן.
השתמשו בהם כמקור לפריסה, לצבעים, לטקסטים ולהתנהגות האינטראקטיבית (ראו `class Component` בסוף כל קובץ). את הממשק האמיתי בונים ב-React לפי `docs/SCREENS.md`.

| קובץ | מסך |
|---|---|
| Lock.dc.html | 1 · כניסה |
| Cases.dc.html | 2 · רשימת תיקים (הדגם המקורי) |
| Cases-explorer.dc.html | 2 · רשימת תיקים כסייר קבצים (סבב 47, D-085; עינת אישרה בסבב העיצוב) |
| Main.dc.html | 3 · מסך העבודה |
| Review.dc.html | 4 · מה יוצא מהמחשב |
| Scores.dc.html | 5 · הזנת ציונים |
| Consult.dc.html | התייעצות: תשובה מעוצבת ושיחות לפי יום (סבב 45, D-086; עינת אישרה בסבב העיצוב) |

הדגם `Cases-explorer.dc.html` נבנה בקנבס לפני הקוד, ושלושה פרטים בו לא נכנסו: עמודת "חומרים" (בקוד: עמודת פעולות), הסטטוס "הופק ✓" (לתקציר התיק אין סימן הוצאה, ולכן הקוד עוצר ב"מוכן להוצאה"), וכפתור "+ תיק חדש" בעץ (בקוד הוא בראש הדף, D-085 §3).

כל הנתונים בדגמים בדויים.
