# דגמי מסכים

קבצי `.dc.html` הם דגמים מכלי העיצוב של Claude: HTML עם JS קטן, שנשען על runtime שלא כלול כאן, ולכן הם לא נפתחים ישירות בדפדפן.
השתמשו בהם כמקור לפריסה, לצבעים, לטקסטים ולהתנהגות האינטראקטיבית (ראו `class Component` בסוף כל קובץ). את הממשק האמיתי בונים ב-React לפי `docs/SCREENS.md`.
