- `/clear` בין משימות, ומשימה אחת בכל פעם.
- מודל חזק לשלבים 0, 2, 3 ו-4; מודל קל יותר ל-UI ולבדיקות.
- לקרוא רק את המסמך שרלוונטי למשימה.
- בדיקות עם mock בלבד.
